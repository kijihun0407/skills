# Directive: 캐러셀 제작 SOP

> Layer 1. 주제를 7장 인스타 캐러셀로 제작하는 전 과정.
> 제작 방식: HTML/CSS → Playwright PNG 자동 추출

---

## 제작 흐름

```
주제 선정
↓
이미지 자료 수집 (인물 사진, 원문/트윗 스크린샷 등)
↓
원고 작성 (outputs/ 폴더에 md 저장)
↓
HTML 제작 (carousel_ai_research.html 복사 → 교체)
↓
브라우저 확인
↓
node export_slides.js → slide_01~07.png 추출
↓
캡션 작성 (댓글 키워드 방식)
↓
인스타 업로드
```

---

## 슬라이드 구성 (7장 고정)

| 장 | 역할 | 배경 |
|:--|:--|:--|
| 1 | 커버 (후킹) | 다크 + 인물/자료 이미지 레이어 |
| 2 | 배경/소개 | 다크 (#0A1628) + 우측 자료 이미지 |
| 3 | 핵심 문제/팩트 | 라이트 (#FFFFFF) + 우측 자료 이미지 |
| 4 | 비교/분석 | 다크 |
| 5 | 체크리스트/인사이트 | 라이트 |
| 6 | 실무 활용법 | 다크 |
| 7 | CTA | 라이트 + 댓글 키워드 박스 |

---

## 커버 슬라이드 필수 요소

- 배경: 주제 관련 자료 이미지 (blur + 어두운 오버레이)
- 인물 사진: 우측 배치, 가장자리 mask 페이드
- 보조 이미지 1~2장: 우측에 floating (원문/트윗 등)
- 헤드라인: 하단 좌측, 흰색 대형 텍스트
- 태그: 상단 좌측 카테고리 pill

---

## 이미지 수집 기준

| 우선순위 | 자료 종류 | 용도 |
|:--|:--|:--|
| 1순위 | 인물 공식 사진 | 커버 person-photo |
| 2순위 | 논문/보고서 원문 캡처 | 신뢰도 강화 |
| 3순위 | 트윗/SNS 원문 스크린샷 | 출처 시각화 |

수집 후 `.tmp/carousel_assets/`에 저장.

---

## 캡션 방식 (DM 자동 발송형)

```
[공감 도입 — 첫 경험·솔직한 반응 1~2줄]

[핵심 정보 5~7줄 — 친근체 (~해요/~더라고요/~거예요)
 구체적 기능·수치·활용법 포함, 읽는 사람이 바로 써먹을 수 있는 내용]

[실제 활용 예시 또는 추가 인사이트 2~3줄]

─────────────────

댓글에 "[키워드]" 남겨주시면
[자료명] DM으로 바로 보내드릴게요 💬
팔로우하고 댓글 남겨주세요!

─────────────────

[한국어 본문 전체 영어 번역 — 공감 도입부터 활용 예시까지 완전 번역]

─────────────────

Comment "[keyword]" below and I'll DM you
[자료 설명] 👇

#한국어태그1 #한국어태그2 #한국어태그3 #한국어태그4 #한국어태그5 #EnglishTag1 #EnglishTag2 #EnglishTag3
```

- 말투: 친근체 고정 (~해요 / ~더라고요 / ~거예요)
- 분량: 15~25줄 (한국어 본문 + 영어 전체 번역)
- 영어 번역: 요약 CTA 2~3줄이 아닌 **한국어 본문 전체 번역** 필수
- 댓글 키워드: 캐러셀 = **"체크"** 고정 / 릴스 = 주제별 짧은 단어
- 팔로우 후 댓글 안내 필수
