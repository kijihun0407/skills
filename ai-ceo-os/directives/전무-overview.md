# 전무 Overview — 콘텐츠 제작 흐름 가이드

> 실제 작업물은 `skills/` 루트의 전무 폴더에 저장됩니다.
> 이 파일은 **방향성·제작 방식·전체 흐름**만 정의합니다.

---

## 전무 폴더 위치

```
skills/
├── 릴전무/       ← 릴스 완성본 (대본·캡션·DM용 자료)
├── 캐전무/       ← 캐러셀 완성본 (슬라이드 원고·이미지 프롬프트·캡션)
└── 바이브전무/   ← 바이브코딩 완성본 (HTML·스크립트·랜딩페이지)
```

---

## 릴전무 — 릴스

### 방향성
- 30~40초 숏폼. 첫 3초 후킹이 전부
- 포맷: [후킹] → [본문 꿀팁] → [CTA 1개]
- 얼굴 비노출 기준 설계 (텍스트·화면녹화·AI 이미지 중심)
- 타겟: 고객 여정 1단계 (호기심 유발)

### 제작 방식
1. `directives/content-research.md` → 주제 선정
2. `directives/reels-to-publish.md` → 대본 작성
3. 대본·캡션·DM 자료 → `릴전무/` 저장
4. 편집: CapCut (자막·컷) / HeyGen (AI 아바타 필요 시)

### 산출물 구조
```
릴전무/
└── [릴스]_{주제}_준비자료.md   ← 대본 + 캡션 + DM 문구 + 해시태그
```

---

## 캐전무 — 캐러셀

### 방향성
- 7장 구성 (커버 1 + 본문 5 + CTA 1)
- 포맷: 충격 후킹 → 인사이트 나열 → 행동 유도
- AI 이미지(ChatGPT Image / GPT-Image-2) 활용한 비주얼 중심
- 타겟: 고객 여정 2단계 (신뢰 형성)

### 제작 방식
1. 주제 선정 → 슬라이드 원고 작성
2. ChatGPT Image 2.0 프롬프트로 이미지 생성
3. 미리캔버스 or Canva에 원고·이미지 적용
4. 완성본 → `캐전무/` 저장

### 디자인 기준
- 스펙: `directives/carousel-design-guide.md` 참조
- 폰트: Noto Sans KR / Pretendard
- 크기: 1080×1350px (4:5) 또는 1080×1080px (1:1)

### 산출물 구조
```
캐전무/
└── [캐러셀]_{주제}_준비자료.md   ← 슬라이드 원고 + 이미지 프롬프트 + 캡션
```

## 바이브전무 — 바이브코딩

### 방향성
- PLAN.md 없이 시작 금지 (DCR 원칙)
- 목적: 랜딩페이지·자동화 스크립트·콘텐츠 HTML 등
- 외주 0원, 직접 제작으로 속도·비용 동시 확보

### 제작 방식
1. PLAN.md 기획서 작성 → CEO 확인
2. Claude Code로 구현
3. 테스트 완료 후 `바이브전무/` 저장
4. 반복 작업은 스킬화 → `skills/` 등록

### 산출물 구조
```
바이브전무/
└── {프로젝트명}/
    ├── PLAN.md       ← 기획서
    └── {결과물}      ← HTML·스크립트 등
```
